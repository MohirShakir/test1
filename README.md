# UPHS Your Scan-in System

This repository contains the UPHS Your Scan-in System application ready for GitHub Pages hosting.

## Files
- `index.html`: The main web application containing the scan terminal, excel log matrix, employee directory, and live clock.

## How to Host on GitHub Pages
1. Push all files in this repository to GitHub.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select `main` (or `master`) branch and `/ (root)` folder, then click **Save**.
5. Your site will be published at `https://<your-username>.github.io/<your-repo-name>/`.
